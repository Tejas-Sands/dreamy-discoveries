# Background music

The three loops here (`bouncy.wav`, `story.wav`, `lullaby.wav`) and everything
in `../sfx/` are **generated by a tiny software synth** in
`scripts/build-audio-assets.mjs` — no samples, no licenses to worry about.
Regenerate (or tweak the tunes) with:

```bash
npm run audio-assets
```

The Director picks a loop per video (`bouncy` for rhymes, `story` for stories,
`lullaby` when the text is about sleep or the palette is `night`). The renderer
loops it and automatically ducks it under the voice.

To use your own track instead, drop a file here and set it in the script:

```json
"music": { "file": "my-track.mp3", "bpm": 110, "mood": "bouncy" }
```

`bpm` matters: characters dance on the beat. Set `"music": "none"` for silence.
